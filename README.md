🎵 Spotify Clone

A sleek music streaming web/mobile app inspired by Spotify, built for learning and experimentation. Users can browse songs, create playlists, and enjoy a modern music player interface.

🚀 Features

Browse and play songs from a curated library

Create, edit, and delete playlists

Play, pause, skip, and shuffle tracks

Responsive UI for desktop and mobile

Beautiful animations and interactive music player

🛠️ Tech Stack

Frontend: HTML, CSS

Backend: Node.js + Express (optional, if implemented)

Database: MongoDB / Firebase (if storing playlists)

Styling & UI: CSS3, Flexbox/Grid, or Tailwind CSS
